# WBS Hierarchy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each project's schedule a PMBOK work breakdown structure (Phase → Deliverable → Task → Subtask, ◆ milestones as phase gates) shown as an indented tree in the Schedule table and Gantt, with rolled-up summary rows, while every existing figure keeps working.

**Architecture:** Every row stays an `ITPMD_Activity_A00` record (five new fields). A pure module `itpm-ui/src/wbs.js` splits rows into **work items** (`p.activities`, the list every existing consumer reads, unchanged in shape) and **summary rows** (`p.wbs`), rolls summaries up after `schedule(p)`, and performs structure edits (add with leaf→summary conversion, move, reorder, delete). `src/bridge.js` loads/saves both lists and exposes the module as `window.__ITPH_WBS`. The prototype UI is patched by `scripts/make-index.mjs`, with the new UI functions in `scripts/wbs-ui.js` (injected like `scripts/manual.js`).

**Tech Stack:** Vanilla JS (ES modules + the prototype's classic script), Vite, Kissflow REST/SDK via `src/bridge.js`, Node's built-in `node --test`, engine CLI (`engine/cli.mjs`).

**Spec:** `docs/superpowers/specs/2026-09-30-wbs-hierarchy-design.md`

## Global Constraints

- The prototype HTML (`ITPMD_Project_Hub_Prototype_LANDBANK (4).html`) is never edited; `itpm-ui/index.html` is only ever regenerated by `node scripts/make-index.mjs` (run inside `itpm-ui/`). Every patch in `make-index.mjs` guards its anchor with `must(...)`.

- Kissflow Select values for `item_type`: exactly `Phase`, `Deliverable`, `Task`, `Subtask`, `Milestone`. Internal type names are lowercase: `phase`, `deliverable`, `task`, `subtask`, `milestone`.
- Short-id prefixes for new rows: `P` phase, `D` deliverable, `N` task/subtask, `X` milestone; existing ids never change.
- Placement: Phase → top only; Deliverable → top or Phase; Task → top, Phase or Deliverable; Subtask → Task only; Milestone → top, Phase or Deliverable.
- Predecessors only on work items. An item with no predecessors starts at the project start date (unchanged `schedule(p)`).
- Summary rows are never typed into; their dates/%/status come from `rollUp`.
- The preview on `http://localhost:3003` writes to LIVE dev data; only build test structures on **Joms Project 2**.
- This folder is not a git repository: there are no commit steps. Back up `runs/itpmd-project-hub/app-spec.json` before editing it (Task 1).

## Review Focus

1. Turning a leaf task into a parent (adding its first subtask, or moving an item under it) must not lose dependencies: items that depended on it now depend on the new child — Task 4 `addItem converts a leaf parent and rewires predecessors`, `moveRow under a leaf converts it`.
2. A flat, legacy project must show identical overall %, forecast finish and S-curve before and after — Task 3 `rollUp never changes work items`, Task 2 `legacy rows load flat`, Task 10 Step 3 before/after comparison.
3. Removing or moving away the last child of a deliverable/task must turn it back into a schedulable item (no crash, no blank dates) — Task 4 `removeRow reverts an emptied deliverable to a work item`, `moveRow reverts the old parent`.
4. An empty phase must render and save without `NaN`/`Invalid date` — Task 3 `empty phase rolls up to blanks`, Task 5 `sumRow` writes `null` dates.
5. Saving after a leaf→summary conversion must not delete that row's Kissflow record (it moves between the two lists) — Task 5 diff over the combined list; Task 10 Step 2 checks the record still exists.

`itpm-ui/src/wbs.js`:

```js
// WBS hierarchy for the Project Hub schedule: Phase → Deliverable → Task → Subtask, with ◆ milestones.
// Pure functions over a project p = { start, pm, activities, wbs }:
//   p.activities — work items (leaf tasks/subtasks/deliverables and milestones): what the scheduler,
//                  S-curve, My tasks, PSR, LD and LEAF read. Same shape as before.
//   p.wbs        — summary rows (phases, and deliverables/tasks that have children), rolled up from children.
// Every row is one ITPMD Activity record in Kissflow (spec: docs/superpowers/specs/2026-09-30-wbs-hierarchy-design.md).
export const TYPES = ["phase", "deliverable", "task", "subtask", "milestone"];
export const LABEL = { phase: "Phase", deliverable: "Deliverable", task: "Task", subtask: "Subtask", milestone: "Milestone" };
export const PARENTS = { phase: [null], deliverable: [null, "phase"], task: [null, "phase", "deliverable"], subtask: ["task"], milestone: [null, "phase", "deliverable"] };

export const typeOf = (r) => (TYPES.includes(r.type) ? r.type : r.ms ? "milestone" : "task");
export function fromKfType(v, isMs) {
  const raw = v && typeof v === "object" ? v.Name || v.value || v.name || "" : v;
  const t = String(raw || "").toLowerCase();
  return TYPES.includes(t) ? t : isMs ? "milestone" : "task";
}
export const toKfType = (t) => LABEL[t] || "Task";

const all = (p) => [...p.activities, ...(p.wbs || [])];
const byOrder = (a, b) => (a.order ?? 0) - (b.order ?? 0);
export const findRow = (p, id) => all(p).find((r) => r.id === id);
export const children = (p, id) => all(p).filter((r) => (r.parent || null) === id).sort(byOrder);
export const descendants = (p, id) => children(p, id).flatMap((k) => [k, ...descendants(p, k.id)]);

export function splitRows(rows) {
  const by = new Map(rows.map((r) => [r.id, r]));
  rows.forEach((r, i) => {
    r.type = typeOf(r); r.parent = r.parent || null; delete r.warn;
    if (r.order === undefined || r.order === null || r.order === "" || Number.isNaN(r.order)) r.order = i;
  });
  for (const r of rows) if (r.parent && !by.has(r.parent)) { r.warn = `Parent ${r.parent} not found`; r.parent = null; }
  for (const r of rows) {
    const seen = new Set([r.id]); let x = r;
    while (x.parent) {
      if (seen.has(x.parent)) { r.warn = "Circular parent link"; r.parent = null; break; }
      seen.add(x.parent); x = by.get(x.parent);
    }
  }
  for (const r of rows) {
    const pt = r.parent ? by.get(r.parent).type : null;
    if (!PARENTS[r.type].includes(pt)) r.warn = r.warn || `${LABEL[r.type]} can't sit under ${pt ? LABEL[pt] : "the top level"}`;
  }
  const hasKids = new Set(rows.filter((r) => r.parent).map((r) => r.parent));
  const activities = [], wbs = [];
  for (const r of rows) {
    r.sum = r.type === "phase" || ((r.type === "deliverable" || r.type === "task") && hasKids.has(r.id));
    (r.sum ? wbs : activities).push(r);
  }
  const warnings = rows.filter((r) => r.warn).map((r) => `${r.id}: ${r.warn}`);
  return { activities, wbs, warnings };
}

export function tree(p, collapsed = new Set()) {
  const out = [];
  const walk = (parent, depth, prefix, hidden) => children(p, parent).forEach((r, i) => {
    const no = prefix ? `${prefix}.${i + 1}` : String(i + 1);
    const kids = children(p, r.id).length;
    out.push({ row: r, depth, no, hasKids: kids > 0, hidden });
    walk(r.id, depth + 1, no, hidden || collapsed.has(r.id));
  });
  walk(null, 0, "", false);
  return out;
}
```

import { rollUp } from "../src/wbs.js";
// test doubles: calendar days as working days; the prototype's actState rules, simplified
const wdDiff = (a, b) => Math.round((Date.parse(b) - Date.parse(a)) / 864e5);
const actState = (a) => a.pct >= 100 ? { k: "done", l: "Complete", r: "G" } : a.late ? { k: "behind", l: "Behind", r: "R" } : a.pct > 0 ? { k: "prog", l: "In progress", r: "I" } : { k: "ns", l: "Not started", r: "N" };
const fns = { wdDiff, actState };
const sched = (id, bS, bF, fS, fF, extra = {}) => leaf(id, { bStart: bS, bFinish: bF, fStart: fS, fFinish: fF, ...extra });

test("rollUp: dates span children, % is duration-weighted, milestones excluded from %", () => {
  const p = proj([
    { id: "P1", name: "Initiation", type: "phase" },
    sched("N2", "2026-10-01", "2026-10-05", "2026-10-01", "2026-10-05", { parent: "P1", dur: 4, pct: 100 }),
    sched("N3", "2026-10-06", "2026-10-15", "2026-10-06", "2026-10-20", { parent: "P1", dur: 12, pct: 0 }),
    sched("X4", "2026-10-15", "2026-10-15", "2026-10-20", "2026-10-20", { parent: "P1", ms: true, type: "milestone", dur: 1, pct: 0 }),
  ]);
  rollUp(p, fns);
  const s = findRow(p, "P1");
  assert.deepEqual([s.bStart, s.bFinish, s.fStart, s.fFinish], ["2026-10-01", "2026-10-15", "2026-10-01", "2026-10-20"]);
  assert.equal(s.dur, 20);
  assert.equal(s.pct, 25);
  assert.equal(s.state.l, "In progress");
});

test("rollUp: nested summaries roll up through levels; actual start counts as start", () => {
  const p = proj([
    { id: "P1", name: "Ph", type: "phase" },
    leaf("D2", { type: "deliverable", parent: "P1" }),
    sched("N3", "2026-10-05", "2026-10-09", "2026-10-05", "2026-10-09", { parent: "D2", aStart: "2026-10-02", pct: 50 }),
  ]);

  assert.equal(findRow(p, "D2").fStart, "2026-10-02");
  assert.equal(findRow(p, "P1").fStart, "2026-10-02");
  assert.equal(findRow(p, "P1").pct, 50);

test("rollUp: status is the worst child; done + not started reads In progress; all done reads Complete", () => {

  assert.equal(mk({ pct: 100 }, { pct: 100 }), "Complete");
  assert.equal(mk({ pct: 0 }, { pct: 0 }), "Not started");
});

const minOf = (xs) => xs.filter(Boolean).sort()[0] || "";
const maxOf = (xs) => xs.filter(Boolean).sort().pop() || "";

export function rollUp(p, { wdDiff, actState }) {
  if (!p.wbs) p.wbs = [];
  for (const s of p.wbs) {
    const w = workUnder(p, s.id);
    if (!w.length) { Object.assign(s, { bStart: "", bFinish: "", fStart: "", fFinish: "", dur: 0, pct: 0, state: null }); continue; }
    s.bStart = minOf(w.map((a) => a.bStart)); s.bFinish = maxOf(w.map((a) => a.bFinish));
    s.fStart = minOf(w.map((a) => a.aStart || a.fStart)); s.fFinish = maxOf(w.map((a) => a.fFinish));
    s.dur = s.fStart && s.fFinish ? wdDiff(s.fStart, s.fFinish) + 1 : 0;
    const work = w.filter((a) => !a.ms); const tot = work.reduce((n, a) => n + (a.dur || 0), 0);
    s.pct = tot ? work.reduce((n, a) => n + (a.dur || 0) * (a.pct || 0), 0) / tot : w.every((a) => a.pct >= 100) ? 100 : 0;
    const states = w.map(actState);
    let worst = states.reduce((m, x) => (RANK(x) > RANK(m) ? x : m));
    if (worst.k === "ns" && states.some((x) => x.k !== "ns")) worst = { k: "prog", l: "In progress", r: "I" };

const PREFIX = { phase: "P", deliverable: "D", task: "N", subtask: "N", milestone: "X" };

export function allowedParents(p, type, selfId) {
  const bad = selfId ? new Set([selfId, ...descendants(p, selfId).map((r) => r.id)]) : new Set();
  const opts = PARENTS[type].includes(null) ? [{ id: null, label: "(top level)" }] : [];
  for (const r of all(p)) if (!bad.has(r.id) && PARENTS[type].includes(r.type)) opts.push({ id: r.id, label: `${r.id} · ${r.name}` });
  return opts;
}
export function nextId(p, type) {
  const rows = all(p); const used = new Set(rows.map((r) => r.id));
  let n = rows.length + 1; while (used.has(PREFIX[type] + n)) n++;
  return PREFIX[type] + n;
}
export const nextOrder = (p) => all(p).reduce((m, r) => Math.max(m, r.order ?? -1), -1) + 1;
const placeError = (p, type, parent, selfId) => (allowedParents(p, type, selfId).some((o) => o.id === (parent || null))
  ? null : `${LABEL[type]} can't go under ${parent || "the top level"}.`);

// a work item that receives its first child becomes a summary row: its links and progress move to `target`
function toSummary(p, row, target) {
  p.activities = p.activities.filter((r) => r !== row);
  row.sum = true; p.wbs.push(row);
  if (target) {
    target.preds = [...new Set([...(row.preds || []), ...(target.preds || [])])].filter((x) => x !== target.id && x !== row.id);
    if (!target.sum) Object.assign(target, { owner: row.owner || target.owner, pct: row.pct || 0, aStart: row.aStart || "", aFinish: row.aFinish || "" });
  }
  for (const a of p.activities) if (a !== target) a.preds = (a.preds || []).map((x) => (x === row.id ? (target ? target.id : null) : x)).filter(Boolean);
  row.preds = [];
}
// a deliverable/task whose last child left becomes a work item again
function toLeaf(p, row) {
  if (row.type === "phase" || !row.sum || children(p, row.id).length) return false;
  p.wbs = p.wbs.filter((r) => r !== row);
  const d = row.bStart || p.start;
  Object.assign(row, { sum: false, dur: 1, preds: [], pct: 0, ms: false, price: 0, manualFinish: "", owner: row.owner || p.pm,
    bStart: d, bFinish: d, pStart: d, pFinish: d, aStart: "", aFinish: "" });
  p.activities.push(row);
  return true;
}

export function addItem(p, item) {
  if (!p.wbs) p.wbs = [];
  const err = placeError(p, item.type, item.parent);
  if (err) return { ok: false, error: err };
  item.parent = item.parent || null; item.order = nextOrder(p);
  if (item.type === "phase") { item.sum = true; p.wbs.push(item); return { ok: true, converted: null }; }
  item.sum = false; item.preds = item.preds || [];
  const parent = item.parent && findRow(p, item.parent);
  let converted = null;
  if (parent && !parent.sum) { p.activities.push(item); toSummary(p, parent, item); converted = parent.id; }
  else p.activities.push(item);
  return { ok: true, converted };
}

export function moveRow(p, id, newParent) {
  const r = findRow(p, id); if (!r) return { ok: false, error: `${id} not found.` };
  newParent = newParent || null;
  const err = placeError(p, r.type, newParent, id); if (err) return { ok: false, error: err };
  const old = r.parent; r.parent = newParent; r.order = nextOrder(p);
  let converted = null, movedTo = null, reverted = null;
  const np = newParent && findRow(p, newParent);
  if (np && !np.sum) {
    const target = r.sum ? descendants(p, r.id).find((x) => !x.sum) || null : r;
    toSummary(p, np, target); converted = np.id; movedTo = target ? target.id : null;
  }
  const op = old && findRow(p, old);
  if (op && toLeaf(p, op)) reverted = op.id;
  return { ok: true, converted, movedTo, reverted };
}

export function reorder(p, id, dir) {
  const r = findRow(p, id); if (!r) return false;
  const sib = children(p, r.parent || null); const i = sib.indexOf(r); const j = i + dir;
  if (j < 0 || j >= sib.length) return false;
  sib.forEach((x, k) => { x.order = k; });
  [sib[i].order, sib[j].order] = [sib[j].order, sib[i].order];
  return true;
}

export const canDelete = (p, id) => !!findRow(p, id) && children(p, id).length === 0;
export function removeRow(p, id) {
  const r = findRow(p, id); if (!r) return { ok: false, reverted: null, error: `${id} not found.` };
  if (!canDelete(p, id)) return { ok: false, reverted: null, error: `${id} still has items under it. Move or delete them first.` };
  p.activities = p.activities.filter((x) => x !== r); p.wbs = (p.wbs || []).filter((x) => x !== r);
  for (const a of p.activities) a.preds = (a.preds || []).filter((x) => x !== id);
  const op = r.parent && findRow(p, r.parent);
  return { ok: true, reverted: op && toLeaf(p, op) ? op.id : null };
}

export function breadcrumb(p, id) {
  const names = []; let r = findRow(p, id);
  while (r && r.parent) { r = findRow(p, r.parent); if (r) names.unshift(r.name); }
  return names.join(" › ");
}
