# Project Discussions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist the prototype's Discussions (messages, @mention notifications, unread counts) in Kissflow and share them between users, with the prototype UI unchanged.

**Architecture:** Three new Kissflow forms are added through the app-spec pipeline. A pure mapping module (`src/discussions.js`) converts between the prototype's `S.chat` / `S.notes` / `S.reads` and Kissflow records; a small API module (`src/discussions-sync.js`) loads, saves and polls them. `src/bridge.js` calls that module at boot, inside its existing debounced `sync()`, and starts a 20 s poll. `scripts/make-index.mjs` exposes the prototype's `render` so the poll can redraw.

**Tech Stack:** Vanilla JS (ES modules), Vite, Kissflow REST via the lowcode client SDK (`kf.api`), Node's built-in `node --test` (no new dependencies), engine CLI (`engine/cli.mjs`).

**Spec:** `docs/superpowers/specs/2026-09-29-project-discussions-design.md`

## Global Constraints

- App `ITPMD_Project_Hub_A00` on `development-landbank-ai`; run engine commands from the app root after `source .kf-env`.
- The prototype HTML (`ITPMD_Project_Hub_Prototype_LANDBANK (4).html`) is never edited; `itpm-ui/index.html` is only ever regenerated by `node scripts/make-index.mjs`.
- Never run a full re-apply. Use `node engine/cli.mjs apply runs/itpmd-project-hub/app-spec.json --no-pages --force` (incremental — unchanged flows are skipped) and then re-send role grants sequentially.
- Messages are append-only: no edit, no delete.
- Poll interval 20 000 ms; no polling while `document.hidden` is true.
- Only notifications whose `go[0] === 'chat'` (mentions) are persisted; other prototype notifications stay local as today.
- Prototype timestamps are Asia/Manila wall-clock strings `YYYY-MM-DD HH:MM:SS`; Kissflow DateTime values are ISO-8601 UTC.
- Kissflow create = `POST /form/2/{acc}/{model}/batch` with `[{ _is_created: true, ...row }]`; update = `POST /form/2/{acc}/{model}/{id}`; Reference and User values are written as `{ _id }`.
- This folder is not a git repository: there are no commit steps. Back up `app-spec.json` before editing it (Task 1).

**Deliberate deviations from the spec (agreed simplifications, flag in review):**
- *Mentions* is stored as a Text field `mentioned_users` holding comma-separated Kissflow user ids — the engine IR has no multi-value User type. The mention *notification* (the part users see) is unaffected.
- The read-marker throttle ("at most one write per project per 10 s") is replaced by "write only when the read count rises", which already limits writes to one per newly read batch of messages.

## Review Focus

1. A poll that lands while the user's own message is still being saved must not show that message twice — Task 3 `poll skips while a save is running` + Task 2 `mergeMessages dedupes by _kfId and keeps unsent local messages`.
2. A message sent just after midnight Manila time must appear under the right day, for everyone — Task 2 `Manila ↔ ISO round trip across midnight`.
3. A message linking an activity or issue that no longer exists must still show (without a broken link) — Task 2 `messageFromKf maps unknown linked item to no link`.
4. `@mentions` of unknown names, of yourself, or of the placeholder PSC/QA users must not create notifications or crash — Task 2 `mentionedKfIds ignores unknown and placeholder users`, Task 3 `sync never sends a notification to myself`.
5. A network failure during a poll must not crash the app or spam toasts; the next tick retries — Task 3 `poll swallows API errors`.

import { call, c, A, sleep } from "./kf.mjs";
import { withGrantPatience } from "../../../engine/agentic.mjs";
const FORMS = ["ITPMD_Discussion_Message_A00", "ITPMD_Notification_A00", "ITPMD_Discussion_Read_A00"];
const HUB = ["Project Manager", "Team Member", "Department Head", "Project Sponsor", "PSC Member", "Hub Administrator"];
const roles = ((await call("GET", `/app_role/2/${c.acc}/list?_application_id=${A}`)).body || []).filter((r) => HUB.includes(r.Name));
if (roles.length !== HUB.length) throw new Error(`expected ${HUB.length} hub roles, found ${roles.map((r) => r.Name).join(", ")}`);
let bad = 0;
for (const f of FORMS) for (const r of roles) {
  const m = { _id: r._id, Name: r.Name, _application_id: A, Role: "Member", Permission: ["Delete"], Kind: "AppRole" };
  const res = await withGrantPatience(() => c.call("POST", `/flow/2/${c.acc}/form/${f}/member/batch?_application_id=${A}`, [m]));
  console.log(`${f} ← ${r.Name}: ${res.status}`);
  if (res.status >= 300) bad++;
  await sleep(400);
}
if (bad) { console.error(`${bad} grant(s) failed`); process.exit(1); }

// Project Discussions — pure mapping between the prototype's chat / notes / reads state and the three
// Kissflow forms (Discussion Message, Notification, Discussion Read). No API calls, so it runs under
// `node --test`. Prototype timestamps are Asia/Manila wall-clock "YYYY-MM-DD HH:MM:SS"; Kissflow is ISO UTC.

export const manilaToIso = (at) => new Date(at.replace(" ", "T") + "+08:00").toISOString();
export const isoToManila = (iso) => new Date(Date.parse(iso) + 8 * 3600e3).toISOString().slice(0, 19).replace("T", " ");
const byAt = (a, b) => a.at.localeCompare(b.at);

// Resolves Kissflow users ↔ the prototype's per-role user ids (`<kfUserId>:<ROLE>`).
export function makeCtx(S) {
  const byKf = {};
  for (const u of S.users) if (u._kfUser && !byKf[u._kfUser]) byKf[u._kfUser] = u.id;
  return {
    projects: S.projects,
    users: S.users,
    protoUserFor(kfUser) {
      if (!kfUser?._id) return "";
      if (!byKf[kfUser._id]) {
        const id = `${kfUser._id}:TEAM`;
        S.users.push({ id, uid: (kfUser.Email || kfUser.Name || kfUser._id).split("@")[0], name: kfUser.Name || kfUser._id, role: "TEAM", unit: "Team Member", status: "Active", last: "", _kfUser: kfUser._id });
        byKf[kfUser._id] = id;
      }
      return byKf[kfUser._id];
    },
    kfUserOf: (protoId) => S.users.find((u) => u.id === protoId)?._kfUser,
  };
}

function refFromKf(p, type, kfId) {
  if (!kfId) return "";
  if (type === "Activity") { const a = p.activities.find((x) => x._kfId === kfId); return a ? `act:${a.id}` : ""; }
  if (type === "Issue") { const i = p.issues.find((x) => x._kfId === kfId); return i ? `issue:${i.id}` : ""; }
  return "";
}
function refToKf(p, ref) {
  const [t, id] = (ref || "").split(":");
  if (t === "act") { const a = p.activities.find((x) => x.id === id); return a?._kfId ? { linked_item_type: "Activity", linked_item: a._kfId } : {}; }
  if (t === "issue") { const i = p.issues.find((x) => x.id === id); return i?._kfId ? { linked_item_type: "Issue", linked_item: i._kfId } : {}; }
  return {};
}

export function mentionedKfIds(text, ctx) {
  const tags = new Set([...String(text).matchAll(/@([a-z0-9._-]+)/gi)].map((x) => x[1].toLowerCase()));
  return [...new Set(ctx.users.filter((u) => u._kfUser && tags.has(String(u.uid).toLowerCase())).map((u) => u._kfUser))].sort();
}

export function messageFromKf(rec, ctx) {
  const p = ctx.projects.find((x) => x._kfId === rec.project?._id);
  if (!p || !rec.sent_at) return null;
  return { pid: p.id, msg: { id: rec._id, who: ctx.protoUserFor(rec.author), at: isoToManila(rec.sent_at), text: rec.message_text || "", ref: refFromKf(p, rec.linked_item_type, rec.linked_item), _kfId: rec._id } };
}

export function messageToKf(p, m, ctx) {
  const who = ctx.kfUserOf(m.who);
  return { project: { _id: p._kfId }, ...(who ? { author: { _id: who } } : {}), sent_at: manilaToIso(m.at), message_text: m.text,
    mentioned_users: mentionedKfIds(m.text, ctx).join(","), ...refToKf(p, m.ref) };
}

export function mergeMessages(chat, recs, ctx) {
  const have = new Set(Object.values(chat).flat().map((m) => m._kfId).filter(Boolean));
  let added = 0;
  for (const r of recs) {
    if (have.has(r._id)) continue;
    const x = messageFromKf(r, ctx);
    if (!x) continue;
    (chat[x.pid] = chat[x.pid] || []).push(x.msg);
    have.add(r._id); added++;
  }
  if (added) for (const k of Object.keys(chat)) chat[k].sort(byAt);
  return added;
}

export function buildChat(projects, recs, ctx) {
  const chat = Object.fromEntries(projects.map((p) => [p.id, []]));
  mergeMessages(chat, recs, ctx);
  return chat;
}

export function readCountsFromKf(chat, readRecs, ctx) {
  const out = {};
  for (const r of readRecs) {
    const p = ctx.projects.find((x) => x._kfId === r.project?._id);
    if (!p || !r.last_read_at) continue;
    const t = new Date(r.last_read_at).toISOString();
    out[p.id] = (chat[p.id] || []).filter((m) => manilaToIso(m.at) <= t).length;
  }
  return out;
}

export function readMarker(msgs, count) {
  const n = Math.min(count, msgs.length);
  return n > 0 ? manilaToIso(msgs[n - 1].at) : null;
}

export const isMention = (n) => Array.isArray(n?.go) && n.go[0] === "chat";

export function noteToKf(n, p, recipientKfId) {
  return { recipient: { _id: recipientKfId }, notification_type: "Mention", title: n.m, detail: n.s || "", link_target: JSON.stringify(n.go), is_read: false,
    ...(p?._kfId ? { project: { _id: p._kfId } } : {}) };
}

const parseGo = (s) => { try { const v = JSON.parse(s); return Array.isArray(v) ? v : []; } catch { return []; } };

// One prototype note per role context I hold, so the bell shows it whichever role I'm viewing as.
export function notesFromKf(recs, myIds) {
  return recs.flatMap((r) => myIds.map((to) => ({ to, m: r.title || "", s: r.detail || "", go: parseGo(r.link_target),
    at: r._created_at ? isoToManila(r._created_at) : "", read: !!r.is_read, _kfId: r._id, _sentRead: !!r.is_read })));
}

export function mergeNotes(notes, recs, myIds) {
  const have = new Set(notes.map((n) => n._kfId).filter(Boolean));
  const fresh = notesFromKf(recs.filter((r) => !have.has(r._id)), myIds);
  notes.push(...fresh);
  return fresh.length;
}

// Project Discussions — Kissflow load / save / poll for the three discussion forms.
// Mapping lives in discussions.js; this file only moves records. The bridge owns when it runs.
import { makeCtx, buildChat, mergeMessages, messageToKf, readCountsFromKf, readMarker, isMention, noteToKf, notesFromKf, mergeNotes } from "./discussions.js";

export const DM = { message: "ITPMD_Discussion_Message_A00", note: "ITPMD_Notification_A00", read: "ITPMD_Discussion_Read_A00" };

export function createDiscussions({ api, acc, q, meId }) {
  const list = async (model) => (await api("GET", `/form/2/${acc}/${model}/list?page_number=1&page_size=1000&${q}`))?.Data || [];
  const create = async (model, row) => (await api("POST", `/form/2/${acc}/${model}/batch?${q}`, [{ _is_created: true, ...row }]))?.[0]?._id;
  const update = (model, kfId, row) => api("POST", `/form/2/${acc}/${model}/${kfId}?${q}`, row);
  const mine = (recs, field) => recs.filter((r) => r[field]?._id === meId);
  const readRow = {}; // pid → { _kfId, count } — the marker last written for me

  async function load(S) {
    const ctx = makeCtx(S);
    const [msgs, notes, reads] = await Promise.all([list(DM.message), list(DM.note), list(DM.read)]);
    S.chat = buildChat(S.projects, msgs, ctx);
    S.notes = notesFromKf(mine(notes, "recipient"), S.__myUserIds);
    const myReads = mine(reads, "reader");
    const counts = readCountsFromKf(S.chat, myReads, ctx);
    for (const r of myReads) { const p = S.projects.find((x) => x._kfId === r.project?._id); if (p) readRow[p.id] = { _kfId: r._id, count: counts[p.id] || 0 }; }
    for (const id of S.__myUserIds) { S.reads[id] = S.reads[id] || {}; for (const p of S.projects) S.reads[id][p.id] = counts[p.id] || 0; }
  }

  async function sync(S) {
    const ctx = makeCtx(S); const me = new Set(S.__myUserIds); let writes = 0;
    for (const p of S.projects) for (const m of S.chat[p.id] || []) {
      if (m._kfId) continue;
      m._kfId = await create(DM.message, messageToKf(p, m, ctx)); writes++;
    }
    for (const n of S.notes || []) {
      if (!isMention(n)) continue;
      if (!n._kfId) {
        if (me.has(n.to)) continue; // a mention of myself (another of my role contexts) stays local
        const to = ctx.kfUserOf(n.to); if (!to) continue;
        n._kfId = await create(DM.note, noteToKf(n, S.projects.find((p) => p.id === n.go[1]), to)); n._sentRead = false; writes++;
      } else if (me.has(n.to) && n.read && !n._sentRead) {
        await update(DM.note, n._kfId, { is_read: true }); writes++;
        for (const x of S.notes) if (x._kfId === n._kfId) { x._sentRead = true; x.read = true; }
      }
    }
    for (const p of S.projects) {
      const count = Math.max(0, ...S.__myUserIds.map((id) => S.reads[id]?.[p.id] || 0));
      const w = readRow[p.id] || (readRow[p.id] = { count: 0 });
      if (count <= w.count) continue;
      const iso = readMarker(S.chat[p.id] || [], count); if (!iso) continue;
      const row = { reader: { _id: meId }, project: { _id: p._kfId }, last_read_at: iso };
      if (w._kfId) await update(DM.read, w._kfId, row); else w._kfId = await create(DM.read, row);
      w.count = count; writes++;
      for (const id of S.__myUserIds) S.reads[id][p.id] = count;
    }
    return writes;
  }

  async function poll(S, { busy, render }) {
    if (globalThis.document?.hidden || busy()) return 0;
    try {
      const [msgs, notes] = await Promise.all([list(DM.message), list(DM.note)]);
      if (busy()) return 0; // a save started mid-read: its message may not have its id yet — try next tick
      const added = mergeMessages(S.chat, msgs, makeCtx(S)) + mergeNotes(S.notes, mine(notes, "recipient"), S.__myUserIds);
      if (added) render();
      return added;
    } catch (e) {
      console.warn("[itph] discussion poll failed — retrying next tick", e?.message || e);
      return 0;
    }
  }

  const startPolling = (S, opts, ms = 20000) => setInterval(() => poll(S, opts), ms);
  return { load, sync, poll, startPolling };
}
