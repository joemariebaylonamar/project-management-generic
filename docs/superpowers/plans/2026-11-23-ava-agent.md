# AVA Project Health and Reporting Agent

**Goal:** Enable AVA in the existing BPI Project Hub for project reviews, missing-data checks, prioritized follow-up and PSR drafts.

**Architecture:** Reuse the current assistant panel, role gates, approval cards and Kissflow persistence. Put deterministic analysis in `itpm-ui/src/ava.js`, expose it through the bridge, and inject assistant enhancements with `scripts/ava-ui.js` from the existing index generator. Use Kissflow Custom Agent exclusively through kf.app.getAgent: validate getContract, execute once, observe completion, and preserve ExecutionId for manual status checks. Clearly distinguish built-in checks from connected AI. Configure only the non-secret Agent ID; no credentials go into the browser.

**Scope:** Current accessible project or visible portfolio only. Explain findings using source record IDs and navigation buttons. Read-only review; PSR narrative changes require Apply and current PM permission. Use the current reporting month, excluding future completions. Missing update timestamps mean freshness cannot be verified, not that work is definitely stale. Preserve submitted reports.

**Design:** Retain BPI tokens, AVA avatar and the existing right-hand assistant panel. Lead with Review project, Find missing updates, Draft PSR and Portfolio briefing prompts. Review cards show severity, source record, reason and next action; narrow screens use a full-width panel. Avoid new global navigation or dashboard redesign.
